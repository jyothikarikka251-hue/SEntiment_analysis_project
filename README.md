# 🐦 Sentiment Analysis on Tweets

## 📌 Project Overview
This project performs **Sentiment Analysis on Tweets** using Natural Language Processing (NLP).  
It classifies tweets into three categories:
- 😊 Positive  
- 😐 Neutral  
- 😡 Negative  

The model uses **VADER Sentiment Analysis** from the NLTK library, which is highly effective for social media text.

---

## 🎯 Objective
- Analyze text data (tweets)
- Clean and process data
- Classify sentiment automatically
- Visualize sentiment distribution

---

## 🛠️ Technologies Used
- Python 🐍
- Pandas
- NLTK (VADER Sentiment Analyzer)
- Matplotlib
